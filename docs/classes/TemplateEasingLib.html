    Class TemplateEasingLib

    缓动库 用于管理模板缓动 for template easing management

    谱面的一个属性 a property of chart

    加载谱面时，先加载事件序列，所需的模板缓动会被加入到缓动库，但并不立即实现，在读取模板缓动时，才实现缓动。 To load a chart, the eventNodeSquences will be first loaded, during which process the easings will be added to the easing library but not implemented immediately. They will be implemented when the template easings are read from data.
