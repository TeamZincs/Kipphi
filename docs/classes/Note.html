    Class Note

    音符 Basic element in music game. Has 4 types: tap, drag, flick and hold. Only hold has endTime; others' endTime is equal to startTime. For this reason, holds are store in a special list (HNList), which is sorted by both startTime and endTime, so that they are accessed correctly and rapidly in the renderer. Note that Hold and HoldNode are not individually-declared classes. Hold is a note with type being NoteType.hold, while HoldNode is a node that contains holds.
