    dumpAnimVar

    • dumpAnimVar(
          sequence: EventNodeSequence<number>,
          from: number,
          to: number,
      ): PhiraAnimVar<number>

      将数值事件节点序列的某个区间编译为Phira的动画变量

      Phira的动画变量与RPE事件共用同一套缓动编号，但不支持模板缓动 （会先由substitute展开）、表达式缓动与贝塞尔缓动 （二者会被按interpolationStep插值成折线）。

      若区间内恒为同一个值，则返回裸数值而非动画数组。

      Parameters

      • sequence: EventNodeSequence<number>

        数值事件节点序列

      • from: number

        起始拍数（含）

      • to: number

        结束拍数（含）

      Returns PhiraAnimVar<number>

      常量或动画事件数组

      Since

      2.2.0
