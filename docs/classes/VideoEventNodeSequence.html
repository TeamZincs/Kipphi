    Class VideoEventNodeSequence

    视频事件节点序列

    结构与EventNodeSequence完全一致（背靠背的Start/End对）， 但序列的语义是阶梯型的：节点处切换视频，节点之间视频恒定。

    序列中的第一个节点必定位于[0, 0, 1]，缺失时会自动补一个空路径节点。

    HEAD -> VS0(t=0) -> VE0(t1) -> VS1(t1) -> VE1(t2) -> ... -> VSn -> TAIL

    与事件序列不同，本序列使用独立的VideoEventNodeSequenceDataKPA2格式， 不导出求值器、宏和final节点。
