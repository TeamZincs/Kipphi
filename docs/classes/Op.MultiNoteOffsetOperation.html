    Class MultiNoteOffsetOperation

    把一组音符整体平移指定拍数。

    音符时刻本身不可变，所以做法是改所属 NoteNode —— 这里直接操作内部结构 而不是组合多个 NoteTimeChangeOperation，因为后者会反复重建 跳数组。lazy 静态方法被显式禁用（无效操作，不应延迟构造）。

    Author

    Zes Minkey Young

    Example

    // 把 4 拍之后的所有音符往后推 2 拍
    const notes = nnList.getNodesAfterOne(nnList.getNodeOf([4, 0, 1])).flatMap(n => n.notes);
    operations.do(new MultiNoteOffsetOperation(nnList, notes, [2, 0, 1]));
